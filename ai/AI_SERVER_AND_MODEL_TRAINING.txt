# AI 서버 및 모델 학습 - VS Code 실행 안내

[폴더 역할]
- D:\datasets\ai : 학습 완료 모델을 사용하는 AI 서버
- D:\datasets\ai\app : FastAPI 서버, 모델 로딩·추론, 이벤트 처리 코드
- D:\datasets\ai\model : 서버에서 사용하는 최종 .pt/.joblib 모델
- D:\datasets\ai\storage\events : 확정 이벤트 JPG·MP4 저장 위치
- D:\datasets\ai_model : 모델 학습 코드와 학습 결과
- D:\datasets\raw : D-Fire·AI Hub 원본/정제 데이터

[팀 프로젝트에 파일 넣는 위치]
- 팀 GitHub 저장소의 최상위 폴더 아래에 ai 폴더 전체를 넣음
- 예시: 팀프로젝트\ai\app\main.py
- AI 서버 진입점: ai\app\main.py
- 모델 로딩·추론 코드: ai\app\models\inference.py
- 영상 처리 코드: ai\app\services\video_service.py
- 이벤트·스냅샷 처리 코드: ai\app\services\event_service.py
- 최종 YOLO 모델: ai\model\yolo.pt
- 분류 모델: ai\model\cnn.pt, mobilenet_v2.pt
- 머신러닝 모델: ai\model\random_forest.joblib, lightgbm.joblib, xgboost.joblib
- 이벤트 저장 폴더: ai\storage\events
- 설치 목록: ai\requirements.txt

[Colab 학습 완료 후 팀원이 할 일]

[GitHub 업로드 범위]

[팀원 PC 학습 환경 설치]
1. Python 3.11 이상과 VS Code를 설치
2. 전달받은 ai_model 폴더와 raw 폴더를 같은 프로젝트 루트에 배치
3. VS Code에서 프로젝트 루트를 열고 PowerShell 터미널 실행
4. 아래 명령 실행

cd D:\datasets\ai_model
py -3.11 -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

[데이터 설치·검사]
- 데이터 압축은 D:\datasets\raw 안에 풀어 위 구조가 되게 함
- D:\datasets\raw\raw처럼 raw 폴더가 두 번 중첩되면 안 됨
- 데이터 확인 명령
cd D:\datasets
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\setup_data.ps1
- "데이터 준비 완료"가 나오면 학습 가능

[5. 데이터 배치 확인]

- 예시 라벨: D:\datasets\raw\dfire\train\labels\001.txt

[7. YOLO11n 전체 100 epoch 학습]
cd D:\datasets\ai_model

python .\src\train_yolo11n.py --data-root D:\datasets\raw --output D:\datasets\ai_model\results_yolo11n_final --epochs 100 --batch-size 16 --image-size 640 --seed 42

[8. CNN·MobileNetV2·YOLO11n·RandomForest·LightGBM·XGBoost 6종 학습]

python .\src\train_all.py --data-root D:\datasets\raw --output D:\datasets\ai_model\results_final_6models --epochs 10 --batch-size 32 --image-size 224 --yolo-image-size 640 --seed 42
